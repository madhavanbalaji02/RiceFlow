Reference genomes README

The following reference genomes were used for SNP calling by the 3kRG project:

Indica:

1. 93-11 latest (best) assembly from BGI from http://rise2.genomics.org.cn/page/rice/download.jsp
- 9311.fa.gz

2. IR64 - the published one by Schatz et al., using Illumina data, downloaded here: http://schatzlab.cshl.edu/data/rice/
- os.ir64.cshl.draft.1.0.scaffold.fa.gz : from the publication  - 2,919 scaffolds

Japonica:
Nipponbare 1.0 - the most recent unified release from IRGSP and MSU (the same underlying sequences).
From MSU  ftp site: 
ftp://ftp.plantbiology.msu.edu/pub/data/Eukaryotic_Projects/o_sativa/annotation_dbs/pseudomolecules/version_7.0/all.dir/
- all.con
From RAP DB (uploaded to the project , from http://rapdb.dna.affrc.go.jp/
- IRGSP-1.0_genome.fasta.gz

Aus:
1 - Kasalath genome: from the Sakai et al,  downloaded here: http://rice50ks.dna.affrc.go.jp/
- kasalath_genome.tar.gz
2- DJ123 hi quality draft from Schatz et al. (done alongside IR64, downloaded here: http://schatzlab.cshl.edu/data/rice/) - os.dj123.cshl.draft.1.0.scaffold.fa.gz
